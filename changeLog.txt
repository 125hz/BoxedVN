BoxedVN 0.1.0 (128)
* Unified fake-fullscreen X11 motion, button and pointer-query coordinates, removing decorated-window offsets from Wine input.
* Kept generated NW.js browser code on the correctness path while returning stable Wine and Boxedwine relay pages to the ARM64 JIT.
* Added persistent 800x600 Wine containers with configurable Windows version, renderer, resolution and shared-folder drive, plus home shortcuts.
* Drew Wine cursors with a Windows-style black edge and removed the legacy home-screen Actions section and launch-setting hint paragraphs.

BoxedVN 0.1.0 (127)
* Expanded the default Wine monitor to contain 1280x960 clients and their decorations without changing the presented game image.
* Restored the device-proven anonymous browser-code interpreter after adaptive page detection failed to observe the title-screen stall.

BoxedVN 0.1.0 (126)
* Kept direct presses and releases at one stable guest coordinate and made trackpad taps observable to polling Windows input loops.
* Restored X11's root/local event-coordinate invariant and forced the optional Wine cursor visible when a game hides it.
* Extended adaptive browser-stall recovery to one proven-stuck PE or anonymous page, and started Chromium-family games borderless fullscreen.

BoxedVN 0.1.0 (125)
* Made Wine's guest-pixel pointer authoritative across direct touch, trackpad motion and guest cursor warps.
* Added separate BoxedVN and Wine cursor trackpad modes, including Wine cursor bitmap and hotspot bridging.
* Replaced broad browser-code interpretation with a single-page forward-progress watchdog and requested maximized NW.js startup.

BoxedVN 0.1.0 (124)
* Made fake-fullscreen pointer queries, warps, motion and button events share the exact 0,0-based pixels presented by UIKit.
* Kept the X11 root and Wine's cached Screen at the same guest resolution instead of leaking decorated-window offsets into the virtual desktop.
* Added an NW.js/Electron compatibility CPU path that interprets anonymous generated x86 while leaving mapped Wine and browser modules JIT-compiled.

BoxedVN 0.1.0 (123)
* Started default Wine game sessions on a 1280x960 monitor so 1280x960 clients never outgrow Wine's cached desktop input geometry.
* Delivered iOS direct-touch and trackpad coordinates to X11 as exact presented guest pixels, without a redundant guest-to-SDL-to-guest transform.
* Resolved Chromium-sized PE images and captured runnable guest instruction windows in first-frame hang snapshots.

BoxedVN 0.1.0 (122)
* Kept direct iOS touch-button state visible to X11 polling as well as button events, fixing Windows engines that ignored otherwise-correct taps.
* Added a one-shot guest thread/EIP snapshot when the opt-in browser boot heartbeat stops for ten seconds.
* Expanded RPG Maker image diagnostics to identify whether a pending encrypted bitmap has reached Blink's image decoder.

BoxedVN 0.1.0 (121)
* Fixed zero-count SHLD/SHRD in the ARM64 JIT when the instruction's flags are dead; these shifts must leave the destination untouched.
* Allowed ordinary Wine users to create files and save directories inside host-backed mounted drives while retaining host filesystem enforcement.
* Removed the disproven ARM64 RCR interpreter fallback now that the FFmpeg failure has been traced to double-shift semantics.

BoxedVN 0.1.0 (120)
* Materialized lazy ARM64 flags before the single-instruction RCR interpreter fallback, so it consumes the carry produced by the preceding shift.

BoxedVN 0.1.0 (119)
* Corrected an ARM64 SHR/RCR carry-chain failure without interpreting an entire guest DLL.
* Retired the obsolete broad ffmpeg interpreter diagnostic that could stall browser-engine event loops.
* Added lowercase aliases for standard Wine shell folders so Windows save-directory creation remains case-insensitive on iOS.

25.0.0
* Updated Wine to latest version
* Internal change to emulate x11 rather than replace winex11 driver.
* Linux file system is now based on Tiny Core Linux 15 instead of Debian 10.  This makes it easier to install packages from the Boxedwine UI.
* Normal (slow) CPU core for 32-bit systems can now use multiple threads.
* Mac ARMv8 is lot more stable.

21.0.1

* Added command line option: -fullscreenAspect  This will enable full screen with letter boxing in order to preserve the aspect ratio.
* Added command line option: -vsync X where X is 0, 1 or 2.  0 is disabled, 1 is enabled and 2 is adaptive.  The default is 0 (disabled).
* Added command line option: -showWindowImmediately  This fixes simple OpenGL GLUT examples.
* OpenGL: Implemented glInterleavedArray, fixed glFeedbackBuffer and fixed glReadPixels when using packed formats.
* Recompiled Wine: will now use SSE for floating point math.  
* Rewrote the audio driver, now winealsa.drv.so will talk to Boxedwine directly.
* Added an implementation for ddraw.dll ddraw7_WaitForVerticalBlank.
* Lots of work on the Mac build.
* Windows build will use DirectX 9 for UI instead of OpenGL

20.1.2

* 64-bit Windows installer will now default to the correct Programe Files to install to.
* Added about 30 more supported extensions to OpenGL.
* Fixed fstat system call, it will now will report the correct size of the file
* Added SSE2 support for both the x64 and normal cores
* Fixed crash in custom winex11.drv and updated file systems to use it
* Launching Boxedwine without any command line arguments will now launch a new UI.  As long as the platform support OpenGL it should work with the UI.
* Windows UI is DPI aware
* Fixed an issue where fast keyboard or mouse input can cause major lag in some games like Sacrafice, Powerslide and Quake 3.
